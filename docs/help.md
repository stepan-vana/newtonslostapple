**How can I contribute to the documentation?**  
Contributions can be submitted by creating a pull request or opening a new issue in our GitHub repository.

**How often is the documentation updated?**  
The documentation is updated on a continuous basis. All recent revisions and additions can be tracked in the *Changelog* section.
