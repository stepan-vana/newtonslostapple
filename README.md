# Newton's Lost Apple

`newtonslostapple.com` is a website where we strive to publish information in a simple and accessible way, making it easy to understand for everyone.

Our website primarily supports education, which is especially important in an era of misinformation and uncertainty. Our goal is to **promote global education**.
